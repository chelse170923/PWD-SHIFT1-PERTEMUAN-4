Selamat Datang!

Ini adalah halaman latihan untuk membuat tombol kembali ke bagian atas halaman. Kamu bisa scroll ke bawah untuk melihat konten lainnya.

Bagian 1

Belajar HTML merupakan langkah awal dalam membuat website.

HTML digunakan untuk menyusun struktur halaman website.

Bagian 2

CSS digunakan untuk mengatur tampilan agar website lebih menarik.

Kita bisa mengubah warna, ukuran, jarak, dan posisi elemen.

Bagian 3

JavaScript membuat website menjadi interaktif.

Pada latihan ini, JavaScript digunakan untuk mengatur tombol.

Bagian 4

Scroll terus ke bawah untuk mencoba tombol kembali ke atas.

Tombol akan muncul setelah scroll melebihi 500px.

Bagian 5

Website ini sengaja dibuat panjang agar bisa di-scroll.

Coba klik tombol panah di kanan bawah setelah muncul.

Bagian 6

Tombol akan membawa halaman kembali ke bagian paling atas.

Selamat mencoba latihan pemrograman web!

Bagian 7

Terus berlatih untuk meningkatkan kemampuan membuat website.

Semoga latihan ini membantu kamu memahami HTML, CSS, dan JavaScript.
